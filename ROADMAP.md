# Roadmap / Дорожная карта

This roadmap describes likely directions, not promises. Priorities may change after classroom use, research review and data-provenance work.

## Near-Term

- Keep README concise while moving deeper research material into `docs/methodology.md`.
- Verify and document map-data provenance, license, data date and simplification method.
- Add a lightweight link/image existence check for documentation assets.
- Improve Firebase deployment notes, including database rules and retention guidance.
- Clarify whether future telemetry should count failed drops, returned pieces or hints.

## Teaching And Research

- Add instructor notes for individual, pair and team classroom modes.
- Provide a sample anonymized CSV and analysis notebook or script.
- Add optional pre/post reflection prompts for regional geography courses.
- Document how to compare difficulty levels without treating leaderboard rank as a high-stakes grade.
- Create a checklist for adapting the game to another country, region set or administrative hierarchy.

## Product And Accessibility

- Improve keyboard accessibility for non-pointer interaction.
- Add reduced-motion and sound-control preferences.
- Test mobile tray behavior across more viewport sizes.
- Consider optional region grouping by federal district or course module.
- Add in-app privacy text for Firebase-enabled deployments.

## Data And Internationalization

- Keep English and Russian labels synchronized.
- Add tests for all region-name translations.
- Review geographic names periodically against the intended teaching context.
- Document politically sensitive naming and boundary choices with source and date.

## Русская версия

### Ближайшие задачи

- Проверить и задокументировать происхождение картографических данных, лицензию, дату и метод упрощения.
- Добавить легкую проверку ссылок и изображений в документации.
- Улучшить заметки по Firebase: правила базы, доступ и срок хранения.
- Определить, нужен ли будущий счетчик ошибок, возвратов детали или подсказок.

### Преподавание и исследование

- Добавить рекомендации для индивидуальной, парной и командной работы.
- Подготовить пример анонимизированного CSV и скрипт анализа.
- Добавить вопросы для входной и итоговой рефлексии.
- Описать адаптацию игры к другим странам, регионам и административным иерархиям.

### Доступность и продукт

- Улучшить управление без мыши.
- Добавить настройки уменьшения анимации и отключения звука.
- Проверить мобильный лоток на большем числе экранов.
- Добавить текст о приватности для deployments с Firebase.
