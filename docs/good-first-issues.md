# Good First Issues / Хорошие первые задачи

These tasks are intended for new contributors. Each one should stay small, testable and easy to review.

## Documentation

- Add a short instructor checklist for a 20-minute classroom session.
- Add a README troubleshooting note for missing CDN access during local launch.
- Add a sample anonymized CSV row and explain each column.
- Improve `THIRD_PARTY_NOTICES.md` after map-data provenance is verified.

## Testing

- Add a script or test that checks README image paths exist locally.
- Add a test that all region names in the TopoJSON file have English translations.
- Add a test for the CSV header generated by the export button.
- Add a mobile viewport check for the tray and language toggle.

## Accessibility

- Review button labels and titles in both languages.
- Add a reduced-motion option for celebration animation.
- Investigate keyboard-friendly alternatives for placing regions.
- Check color contrast for the tray, status pill and leaderboard tables.

## Research Readiness

- Draft a short pre/post reflection prompt for students.
- Add guidance for anonymizing Firebase exports before publication.
- Document how to report repeated attempts in a classroom study.
- Create an adaptation checklist for a different administrative geography.

## Русская версия

- Добавить краткий чек-лист преподавателя для занятия на 20 минут.
- Проверить, что все названия регионов из TopoJSON имеют английский перевод.
- Добавить проверку локального существования картинок из README.
- Подготовить рекомендации по анонимизации CSV перед публикацией.
- Улучшить доступность: подписи кнопок, контраст, уменьшение анимации.
